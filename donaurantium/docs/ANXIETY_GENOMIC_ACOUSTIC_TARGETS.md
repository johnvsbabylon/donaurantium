*   **Needle:** **6 Hz Theta**. This induces a state of reduced "critical filtering" where the high-reactivity serotonin system is calmed without triggering the startle reflex.

### COMT — The Dopamine Regulator
*   **The Problem:** Moderate expression (19.1) in the PFC. If it runs too fast, dopamine is cleared too quickly (Worrier). If too slow, it builds up (Warrior).
*   **Acoustic Modulation:** Chronic noise *increases* methylation, reducing COMT expression and causing an anxiety-inducing catecholamine buildup. 
*   **The Solution:** Organized, low-amplitude sine tones reduce the stress load on the enzyme. **40 Hz Gamma** supports the prefrontal circuits where COMT is most active.
*   **Needle:** **40 Hz Gamma** (PFC support) + **10 Hz Alpha** (prefrontal-limbic top-down control).

### GABRA2 — The Silent Brakes
